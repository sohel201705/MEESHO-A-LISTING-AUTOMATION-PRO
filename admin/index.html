Local Backup, Restore & Factory Reset

Free mode: backup files are downloaded to your own computer. No Cloud Functions or Firebase Storage backup is used.

Step 1: Download a JSON backup before resetting. Keep the file somewhere safe on your computer.

Step 2: Use Restore Backup to select a previously downloaded JSON file. Restoring replaces known app data, while preserving the current Admin record.

Step 3: For a factory reset, download the backup, type the exact phrase below, then confirm. This free panel clears known app Firestore data only; Firebase Authentication sign-in accounts remain and can sign in again without membership data.
